# Blinkit Sales Analysis Dashboard | Microsoft Excel

## Project Overview

This project presents an interactive **Blinkit Sales Analysis Dashboard** developed in Microsoft Excel to analyze sales performance, product trends, and outlet-level performance.
The analysis transforms raw sales data into actionable insights using **data preparation, Pivot Tables, Pivot Charts, KPI metrics, and interactive filters**.


## Business Problem

The objective of this analysis is to understand:

- Overall sales performance
- Product category contribution
- Sales distribution by fat content
- Outlet performance by size and location
- Sales trends based on outlet establishment year
- Performance across different outlet types
- Customer rating patterns

## Analysis Performed

### 1. Sales by Fat Content
Analyzed the contribution of Low Fat and Regular products to overall sales.

### 2. Sales by Item Type
Compared sales performance across different product categories to identify stronger-performing segments.

### 3. Sales by Outlet Establishment
Analyzed sales trends based on the establishment year of outlets.

### 4. Sales by Outlet Size
Compared performance across Small, Medium, and High-sized outlets.

### 5. Sales by Outlet Location
Evaluated sales performance across different location tiers.

### 6. Outlet Type Performance
Compared sales and item-level performance across different outlet types.


## Key Insights

- **Low Fat products** account for the majority of overall sales.
- **Medium-sized outlets** contribute the highest share of sales.
- Sales performance differs significantly across product categories.
- Outlet location and outlet type are important factors in overall sales performance.
- Establishment-year analysis provides visibility into changes in outlet sales performance over time.
